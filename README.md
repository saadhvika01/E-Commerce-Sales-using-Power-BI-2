# E-Commerce-Sales-using-Power-BI-2
# Power BI Assignment 2 – DAX & Data Visualization

## Project Overview
This project focuses on analyzing sales data using Microsoft Power BI. The main objective is to understand sales performance, profit, order quantities, and sales targets through data transformation, DAX calculations, and interactive visualizations.

## Tools Used
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query

## Dataset
The project uses three tables:
- List of Orders: Contains order dates, customer details, locations, and product categories.
- Order Details: Contains order IDs, categories, sub-categories, quantities, sales amounts, and profit.
- Sales Target: Contains category-wise sales targets and monthly target information.

## DAX Calculations

# Calculated Columns
- **Category Type:** Combines category and sub-category information.
- **Revenue per Order:** Calculates revenue using amount and quantity.
- **Sales Category:** Classifies sales amounts as above or below average.

# Measures
- **Order Count:** Calculates the distinct number of orders.
- **Average Profit in Delhi:** Calculates the average profit for orders associated with Delhi.
- **YTD Sales:** Calculates year-to-date sales.

## Visualizations
The report includes the following visualizations:

1. Sales Target Achievement by Category:** Compares actual sales with sales targets.
2. Max Profit Margin by Sub-Category:** Displays profit margin across sub-categories using a donut chart.
3. Monthly Sales Trend:** Shows changes in sales over time.
4. Profit and Quantity by Sub-Category:** Examines the relationship between profit and quantity.
5. Sales KPI Cards:** Displays total sales amount and total sales target.
6. Sales Performance Matrix:** Compares sales across categories and months.
7. Geographic Sales Analysis:** Displays sales information by location.
8. Sales Distribution by Sub-Category:** Uses a treemap to compare sales across sub-categories.
9. Order Count Analysis by State:** Uses a funnel chart to analyze order counts by state.

## Project Objective
The purpose of this project is to develop practical skills in data modeling, DAX calculations, and data visualization. The report helps present sales information in a clear and understandable format, making it easier to identify trends and compare business performance.
